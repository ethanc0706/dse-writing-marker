# 扣題

題目是合約。每一截，都要有落點。

## 一、拆題

逐字抄題，圈出要落點的詞。

例：「我曾覺得高中生涯十分迷茫，後來卻發現生活中的精彩」

| 成分 | 要求 |
|---|---|
| 曾覺得 | 過去的認知，須有「當時以為」的痕跡 |
| 高中生涯 | 時段與處境，不可寫成初中、小學、大學 |
| 十分迷茫 | 具體的迷惘，須有緣由，不可只寫「很迷茫」 |
| 後來卻發現 | 轉折，須有觸發點，不可忽然頓悟 |
| 生活中的精彩 | 題眼。須界定，須落在日常 |

## 二、三根樁

| 位置 | 作用 | 例 |
|---|---|---|
| 前四分之一 | 立題，寫出「曾覺得」 | 升上中四，我一度覺得高中生涯是一片迷茫 |
| 正中 | 設問或轉折，把題眼舉起 | 生活的精彩，到底在何方 |
| 收束 | 回扣，答覆設問 | 後來我才明白，那時我問錯了方向 |

三根樁齊，扣題即緊。缺一根，內容封 7；缺兩根，封 6。

## 三、設問必回

文中問了的，末段要答。

- 問而不答：有懸念，無交代，讀者空手而回。
- 答而不問：發現無對象，像自言自語。
- 問答相應：題旨成立。

設問的位置在正中，答案的位置在收束。兩點之間，是全文的張力。

## 四、界定

抽象題眼，首次出現前後，要有一句自己的界定。

- 「精彩」：精彩未必熱鬧。
- 「美好」：美好不必有用。
- 「成長」：成長是知道自己怕甚麼。

沒有界定，題眼會滑。學生寫着寫着，「精彩」變成「幸福」，再變成「美好」，最後變成「溫暖」。三滑之後，題目不見了。

界定句要短，要像判斷，不像解釋。

## 五、換詞測試

把題眼換成近義詞，重讀全文。

- 文意不變：扣題失敗。寫的是那個詞的鄰居，不是那個詞。
- 文意走樣：扣題成立。

例：把「精彩」換成「美好」，全文仍通，即未寫出精彩。

## 六、四種離題

1. **全離**：主旨與題旨無關。
2. **半離**：前半扣題，後半另起。
3. **偷換**：題眼滑移，寫成另一個詞。
4. **空扣**：題目字眼反覆出現，內容不落。

前兩種封頂；第三種內容封 6；第四種內容封 5。

## 七、自檢

寫完扣題一節，問四句：

1. 題目每一個圈詞，文中有落點嗎？
2. 三根樁在哪三段？
3. 文中問了甚麼？末段答了嗎？
4. 題眼有界定嗎？界定句在哪？
