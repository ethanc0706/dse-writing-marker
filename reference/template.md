# 輸出模板

七節，次序固定。每節寫多少，見下表。

| 節 | 內容 | 長度 |
|---|---|---|
| GRADES | 五項、加權、錯別字、總分、百分位、級 | 一表 |
| MARKING CRITERIA | 勾選表 | 一表 |
| QUESTION | 扣題、立意、選材、結構 | 400–700 字 |
| WRITING STYLE | 句長、文白、陳腔、白描 | 300–500 字 |
| LINE-TO-LINE | 逐句，原文／改句／理由 | 8–15 條 |
| 諾貝爾級筆法 | 三至五處，可轉移的寫法 | 300–500 字 |
| CONCLUSION | 三件事，最該改的放最後 | 150–250 字 |

## 一、GRADES

```
內容　6／10 × 4 ＝ 24
表達　5／10 × 3 ＝ 15
結構　6／10 × 2 ＝ 12
字體標點　5／10 × 1 ＝ 5
錯別字　4 個，＋2
────────────────
總分　58／103（56.3%）
級別　四級（距五級 5 分）
```

分數之後，一句判斷。這一句要說出距離在哪裏，不說「繼續努力」。

## 二、勾選表

按 Marking Criteria 原表勾選，可多選。

| 概念 | ☐ 準確　☐ 偷換　☐ 含混 |
| 取材 | ☐ 精當　☐ 恰當平實　☐ 陳套　☐ 不當 |
| 情節 | ☐ 完整　☐ 平鋪直敘　☐ 牽強 |
| 邏輯 | ☐ 嚴謹　☐ 尚可　☐ 欠嚴謹 |
| 表達手法 | ☐ 敘事生動　☐ 善用細節　☐ 描寫細膩　☐ 手法單一　☐ 堆砌詞藻 |

勾選之後，在表下寫一句：哪一項最傷，哪一項最可取。

## 三、LINE-TO-LINE

格式：

> **原文**：……
> **改句**：……
> **理由**：一句，二十字內。

排序：先內容，後文字。內容錯了，文字再美也是替錯事化妝。

只改必要處。學生的聲音，留着。

## 四、諾貝爾級筆法

三至五處，每處三行：

1. **寫法**：一句，說明手法。
2. **示例**：一句，可直接用。
3. **用法**：一句，說明何時用，如何換。

標準：可轉移。換一個題目，仍能用。

不寫「多讀多寫」一類的話。

## 五、CONCLUSION

三件事：

1. 這篇最強的一處（具體到一句）。
2. 這篇最傷的一處（具體到一句）。
3. 下一步只做一件事。

第三件放最後，寫成動作，不寫成決心。

> 下次寫完，先圈題目每一個詞，數一數文中落點。缺一個，補一段。

## 六、語氣

評語只做一件事：陳述。

說「這句多了一個『的』」，不說「這句可以更好」。前者可以改，後者只是安慰。安慰的話，考場上換不到一分。

「加油」「繼續努力」「你有潛質」，一概不寫。這幾句留在家長會，不留在此處。

嚴苛是方法。分數給得準，學生才知道距離在哪裏。
