# 排毒

刪句之前，先分信息與節奏。

## 一、一條界線

問：這句話是在提供信息，還是在提供節奏。

提供節奏的，留。

> 他沒有哭鬧，只是默默垂下頭。

沉默本身是信息。刪了，人就沒了。

重複的碎片，刪。

> 文件沒了。消失了。再也找不到了。

三句只說一件事。留一句，留最重的那句。

界線畫不清，會把學生的靈氣當成囉嗦刪掉。刪廢話是紀律；刪文學是無知。

## 二、必掃十八條

| 條 | 例 | 處理 |
|---|---|---|
| 假對比 | 不是不愛，只是不懂表達 | 直說：他不懂表達 |
| 起跑式鋪墊 | 在開始之前，我想先說 | 刪，直接開始 |
| 與假想敵辯論 | 有人說……但我認為 | 無人說，即刪；有人說，引明 |
| 句式開頭復讀 | 當我……當我……當我…… | 留一句，其餘換句式 |
| 限定詞堆疊 | 在一定程度上，某種意義上 | 刪至一個 |
| 被動與缺主語 | 被認為是…… | 補主語，改主動 |
| AI 高頻詞 | 賦能、閉環、維度、鏈接 | 換日常詞 |
| 意義拔高 | 這便是人生的真諦 | 刪，留事 |
| 模糊關聯 | 與此同時、不僅如此 | 無實指即刪 |
| 句尾補充式拔高 | ……，這未嘗不是一種成長 | 刪末句 |
| 宣傳語 | 讓我們一起…… | 刪 |
| 借權威 | 正如蘇軾所言（引文不切） | 刪，或換切題的一句 |
| 迴避「是」「有」 | 呈現出、具備著 | 改「是」「有」 |
| 層疊的「的」 | 他的母親的朋友的兒子 | 拆句 |
| 進行＋動詞 | 進行討論 | 討論 |
| 被字句堆疊 | 被老師被同學被家人 | 拆開，留一個被 |
| 隨著……的發展 | 隨著科技的發展 | 刪，直寫變化 |
| 套話收尾 | 總而言之，言而總之 | 刪，停在事 |

## 三、六條待譯

先問「這是廢話還是文學」，再決定。

**單句收尾與戲劇性碎片。** 「他笑了。而已。」若前文夠重，這是留白；前文不足，這是故弄玄虛。

**格言與偽深度。** 「人生就是一場修行。」後文撐得住，留；撐不住，刪。

**強湊三段式。** 三句同構，讀來整齊而空。留兩句，第三句換句式或刪。

**破折號濫用。** 一律改逗號、句號或冒號。考場上不寫破折號。

**四字詞排比。** 六個四字連發，喘不過氣。留兩個，其餘改散句。

**生造複合詞。** 「時光的褶皺」「記憶的褶邊」。意象不成立，改直說。

## 四、六條忽略

與手寫作文無關，不必理：粗體裝飾、裝飾性標題、JSON 引號、客服腔、知識邊界免責、談論上一稿。

## 五、報告格式

| 原句 | 命中 | 刪或留 | 理由 |
|---|---|---|---|
| 心中一股暖流湧現 | 意義拔高 | 刪 | 以直說代白描 |
| 他沒有哭鬧，只是垂下頭 | 單句收尾 | 留 | 沉默是信息 |

留的，標明文學功能。刪的，寫明命中哪一條。
