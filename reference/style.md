# 文風

## 一、文白

白話八成半，文言一成半。文言用來點睛，不用來撐場。

- 議論文：文白 1.5 : 8.5。
- 記敘文：文言可稍多，但不超過兩成。
- 通篇文言，是炫技；通篇口語，是不文。

文言的用法，三種：

1. 一句判斷。「人不能擇其所遇，卻能擇其所見。」
2. 一個虛詞。「故」「乃」「遂」「然」。
3. 一次引經。引一句即止，下一句必須是自己的話。

文言的忌諱，三種：

1. 生造。逼仄、囁嚅、岑寂，用錯不如不用。
2. 堆砌。四字一連六個，讀者喘不過氣。
3. 兩把聲音。前十四段白話，第十五段忽然文言，文氣即裂。

## 二、句長

| 指標 | 合格 | 危險 |
|---|---|---|
| 平均句長 | 20–26 字 | < 16 或 > 34 |
| 最長句 | ≥ 50 字 | < 35 |
| 十字以下比例 | ≤ 25% | > 40% |
| 句長變異（CV） | ≥ 0.55 | < 0.45 |

測法：

```bash
python3 scripts/textstats.py essay.txt
```

**長句為主，短句為收。** 敘述用逗號推進，句號留給停頓與收束。一段之中，短句不過一兩。

反例（電報體，不可學）：

> 書包壓肩。上層？算了。下層覓得一位，坐下，整個人塌進椅背。

六個句號，三十字。這是分鏡腳本，不是文章。

正例：

> 上層的梯級就在右手邊，我抬頭看一眼，到底沒上去；一日八堂課下來，兩條腿早已不聽使喚。

一句三十七字，三個動作，一個停頓。長句的力量，在於它可以容納猶豫。

## 三、白描

寫動作，不寫感受。讓細節自己說話。

| 不寫 | 改寫 |
|---|---|
| 他很緊張 | 他的手在褲子上蹭了兩下 |
| 我很感動 | 我別過臉，看窗外 |
| 母親很愛他 | 她蹲下來，替他把鞋帶綁好，綁了兩次 |
| 老人很恩愛 | 他伸手，替她把衣領翻好 |

感受是結論，動作是證據。文章要給證據。

## 四、意象

一個意象，貫穿全文。

- 紗布：看不清遠近。開頭戴，結尾收。
- 鐘：迷茫是看鐘，精彩是忘記鐘。
- 車：同一程車，同一條路，看的人不同。

意象不是裝飾，是主題的化身。開頭出現，中間變形，結尾回收。

意象不可多。三個以上，讀者記不住。

## 五、克制

不多說一句，不點破最後一層。

- 結尾停在人事，不跳人生。
- 判斷句只一句，其餘交給讀者。
- 情緒到了頂點，反而要收。寫一個動作，不寫一滴淚。

留白不是空白。留白是讓讀者走完最後一步。

## 六、禁用清單

**標點**

- 破折號（——）。用逗號、句號、冒號代替。

**詞語**

- 接住、撐住、穩住、懂、我都在這裡。
- 其實、很清楚、很簡單、不繞、很現實、底氣。

**句式**

- 不是……而是……（最強 AI 訊號）
- 先說結論
- 先給你一個粗暴但很真實的結論
- 你已經撐太久了

**過渡**

- 總結來說、首先其次再者、一方面……另一方面……
- 三段式排比，連發三次。

## 七、AI 味的三個來源

1. **句式**。「不是 A，而是 B」的出現率，AI 遠高於人。改為直陳：「A 不是 B。」或「B 才是 A。」
2. **用詞多樣性過高**。人會重複同一個詞，AI 每隔兩句換一個近義詞。允許重複。
3. **三連同構**。三例並排，句式一致，是 AI 的習慣。三例之中，讓一句變形。

## 八、改後三查

1. 有無破折號？
2. 有無「不是……而是……」？
3. 有無為求文雅而生造的詞？

三查有一，重改。
